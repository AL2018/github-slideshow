# AGENTS.md — github-slideshow

Entry file for any AI agent or person working in this repository. It is tool-neutral. `CLAUDE.md` imports it, so
edit this file, not that one.

This is GitHub's 2019 "github-slideshow" training repository (a Jekyll and reveal.js slide deck from GitHub Learning
Lab; default branch `master`, last commit 24 Jan 2019). It isn't part of the Little Cocoa estate: nothing here is
built, deployed or depended on, and no estate work belongs in it. The estate's rules live in `AL2018/littlecocoa-docs`,
starting with `docs/cc-briefs/METHOD-02-how-we-work.md`.
